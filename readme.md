# Push_swap 명령어 정리

Push_swap은 **스택 A와 B**를 조작하는 11종의 명령어를 사용한다. 초기에는 정렬할 정수가 스택 A에 주어지고, 스택 B는 비어 있다. 각 스택의 **맨 위(top)** 를 기준으로 동작을 정의한다.

## 명령어 11종

| 명령어 | 이름 | 동작 |
|---|---|---|
| `sa` | swap a | A의 맨 위 두 원소를 교환한다. 원소가 2개 미만이면 아무 동작도 하지 않는다. |
| `sb` | swap b | B의 맨 위 두 원소를 교환한다. 원소가 2개 미만이면 아무 동작도 하지 않는다. |
| `ss` | swap both | `sa`와 `sb`를 동시에 수행한다. |
| `pa` | push a | B의 맨 위 원소를 꺼내 A의 맨 위에 놓는다. B가 비어 있으면 아무 동작도 하지 않는다. |
| `pb` | push b | A의 맨 위 원소를 꺼내 B의 맨 위에 놓는다. A가 비어 있으면 아무 동작도 하지 않는다. |
| `ra` | rotate a | A의 모든 원소를 한 칸씩 위로 이동한다. 맨 위 원소는 맨 아래로 간다. |
| `rb` | rotate b | B의 모든 원소를 한 칸씩 위로 이동한다. 맨 위 원소는 맨 아래로 간다. |
| `rr` | rotate both | `ra`와 `rb`를 동시에 수행한다. |
| `rra` | reverse rotate a | A의 모든 원소를 한 칸씩 아래로 이동한다. 맨 아래 원소는 맨 위로 간다. |
| `rrb` | reverse rotate b | B의 모든 원소를 한 칸씩 아래로 이동한다. 맨 아래 원소는 맨 위로 간다. |
| `rrr` | reverse rotate both | `rra`와 `rrb`를 동시에 수행한다. |

## 동작 예시

아래 배열은 **왼쪽이 스택의 맨 위**라고 가정한다. 각 예시는 독립적이다.

### 교환: `sa`

```text
실행 전 A: [3, 1, 2]
실행 후 A: [1, 3, 2]
```

### 이동: `pb`

```text
실행 전 A: [3, 1, 2]    B: [8, 9]
실행 후 A: [1, 2]       B: [3, 8, 9]
```

### 정방향 회전: `ra`

```text
실행 전 A: [3, 1, 2]
실행 후 A: [1, 2, 3]
```

### 역방향 회전: `rra`

```text
실행 전 A: [3, 1, 2]
실행 후 A: [2, 3, 1]
```

## 구현 시 구분할 점

- **명령어 종류는 11개**지만, 내부 자료구조 조작은 `swap`, `push`, `rotate`, `reverse_rotate`의 **4가지 기본 동작**으로 공통화할 수 있다.
- `ss`, `rr`, `rrr`은 두 스택에 동작을 적용하더라도 **출력 명령어는 각각 한 줄, 연산 횟수는 1회**로 취급한다.
- 정렬 결과가 아니라 **명령어 문자열을 표준 출력(stdout)에 한 줄씩 출력**한다. 예: `sa\npb\nra\n`.
- 스택의 내부 구현 방식(배열, 연결 리스트 등)은 별도로 지정되지 않는다.

## 최종 목표

명령어들을 조합해 **스택 A를 오름차순으로 정렬하고 스택 B를 비운다.** 가능한 한 적은 명령어로 달성하는 것이 성능 평가의 핵심이다.
