이번에는 스택의 바닥을 기준으로 아래쪽에 정렬하고, 각 스택의 TOP이 가장 위에 있는 숫자가 되도록 11종 명령어 예시를 전부 수정했어.

# Push_swap 명령어 정리

## 1. 명령어 요약

| 명령어   | 대상    | 동작                  |
| ----- | ----- | ------------------- |
| `sa`  | A     | TOP 두 원소 교환         |
| `sb`  | B     | TOP 두 원소 교환         |
| `ss`  | A + B | 양쪽 TOP 두 원소 교환      |
| `pa`  | B → A | B의 TOP을 A의 TOP으로 이동 |
| `pb`  | A → B | A의 TOP을 B의 TOP으로 이동 |
| `ra`  | A     | TOP을 바닥으로 이동        |
| `rb`  | B     | TOP을 바닥으로 이동        |
| `rr`  | A + B | 양쪽 TOP을 바닥으로 이동     |
| `rra` | A     | 바닥을 TOP으로 이동        |
| `rrb` | B     | 바닥을 TOP으로 이동        |
| `rrr` | A + B | 양쪽 바닥을 TOP으로 이동     |

## 2. 기본 규칙

Push_swap은 두 개의 스택 `a`, `b`를 이용해 정수를 정렬하는 프로그램이다.

- 스택은 후입선출(LIFO) 구조다.
- 원소는 각 스택의 바닥부터 위로 쌓인다.
- 출력에서는 스택의 바닥을 아래쪽에 고정한다.
- 각 스택에서 가장 위에 있는 숫자가 TOP이다.
- 빈 공간은 숫자 위쪽에 표시한다.
- 정수 출력에는 `%5d` 형식을 사용한다.
- 명령어는 총 11종이다.

### 출력 형식

```
[ -154][     ]  ← A의 TOP
[  -27][     ]
[   21][     ]
[  333][     ]
[  444][ -247]  ← 각 스택의 바닥
[    a][    b]
```

위 상태에서 A의 TOP은 `-154`, B의 TOP은 `-247`이다.

## 3. Swap — 상단 두 원소 교환

### `sa` — Swap A

스택 A의 맨 위 두 원소를 교환한다. 원소가 2개 미만이면 아무 동작도 하지 않는다.

실행 전

```
[ -154][     ]
[  -27][     ]
[   21][     ]
[  333][     ]
[  444][ -247]
[    a][    b]
```

실행 후

```
[  -27][     ]
[ -154][     ]
[   21][     ]
[  333][     ]
[  444][ -247]
[    a][    b]
```

### `sb` — Swap B

스택 B의 맨 위 두 원소를 교환한다. 원소가 2개 미만이면 아무 동작도 하지 않는다.

실행 전

```
[ -154][     ]
[  -27][     ]
[   21][     ]
[  333][   88]
[  444][ -247]
[    a][    b]
```

실행 후

```
[ -154][     ]
[  -27][     ]
[   21][     ]
[  333][ -247]
[  444][   88]
[    a][    b]
```

### `ss` — Swap Both

`sa`와 `sb`를 동시에 실행한다.

실행 전

```
[ -154][     ]
[  -27][     ]
[   21][     ]
[  333][   88]
[  444][ -247]
[    a][    b]
```

실행 후

```
[  -27][     ]
[ -154][     ]
[   21][     ]
[  333][ -247]
[  444][   88]
[    a][    b]
```

## 4. Push — 스택 간 원소 이동

### `pa` — Push A

스택 B의 TOP을 제거하고 스택 A의 TOP에 추가한다.

B가 비어 있으면 아무 동작도 하지 않는다.

실행 전

```
[ -154][     ]
[  -27][     ]
[   21][     ]
[  333][     ]
[  444][ -247]
[    a][    b]
```

실행 후

```
[ -247][     ]
[ -154][     ]
[  -27][     ]
[   21][     ]
[  333][     ]
[  444][     ]
[    a][    b]
```

### `pb` — Push B

스택 A의 TOP을 제거하고 스택 B의 TOP에 추가한다.

A가 비어 있으면 아무 동작도 하지 않는다.

실행 전

```
[ -154][     ]
[  -27][     ]
[   21][     ]
[  333][     ]
[  444][ -247]
[    a][    b]
```

실행 후

```
[     ][     ]
[  -27][     ]
[   21][     ]
[  333][ -154]
[  444][ -247]
[    a][    b]
```

## 7. 구현 시 참고사항

11종 명령어는 내부적으로 4가지 기본 동작으로 구분할 수 있다.

| 기본 동작          | 명령어                 |
| -------------- | ------------------- |
| Swap           | `sa`, `sb`, `ss`    |
| Push           | `pa`, `pb`          |
| Rotate         | `ra`, `rb`, `rr`    |
| Reverse Rotate | `rra`, `rrb`, `rrr` |

내부 구현은 공통화할 수 있지만, 명령어 출력은 구분해야 한다.

예를 들어 `ss`는 A와 B에 Swap을 각각 적용하지만, 출력은 `ss\n` 한 줄이며 연산 횟수도 1회로 계산한다.

스택 시각화는 디버깅용이며, 실제 `push_swap` 프로그램의 표준 출력에는 정렬 명령어만 출력해야 한다.
